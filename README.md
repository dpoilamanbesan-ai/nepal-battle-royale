# One More Joke

A responsive random joke generator built with React, TypeScript, Vite, Tailwind CSS, and Lucide. Fetches jokes from [JokeAPI](https://jokeapi.dev/) with safe mode enabled. Pick a category, fetch another joke, copy or share it, and save favorites to local storage.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to type-check and create the production build. Joke fetching requires an internet connection.
